# Warung Teh Nopi

Landing page company profile warung makan/ayam geprek berbasis Laravel + Blade + Vite.

## Jalankan
```bash
composer install
npm install
npm run dev
php artisan serve
```

## Fitur
- Responsive desktop/tablet/mobile
- Navbar sticky + mobile menu
- Hero + CTA WhatsApp
- Filter menu
- Tentang kami
- Keunggulan
- Testimoni
- Lokasi + Google Maps
- Floating WhatsApp
- Animasi scroll reveal

## Data yang perlu diganti
Nomor WhatsApp, alamat, jam buka, dan link Maps masih berupa contoh.
